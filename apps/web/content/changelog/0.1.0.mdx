- **Academy** — four outcome-based tracks (your first Hinglish reel, podcast clips
  with chapters, captions inside Premiere, agency workflow), each with step-by-step
  progress and a one-time credit reward on completion.
- **Help centre** — ten articles across getting started, editing, captions and
  styles, exporting, billing, account, plugins and troubleshooting, searchable from
  the app.
- **Support** — file a ticket from Settings → Support, optionally attaching a
  diagnostics bundle, and track its status from the same page.
- **What's new** — a one-time modal the next time you open the app after a new
  version like this one ships.
