## Emphasising a word

Select a word in the transcript and apply an emphasis preset (bold pop, colour pulse,
scale bounce) to make it stand out on screen the moment it's spoken.

## Adjusting word timing

If a word's on-screen timing looks off against the audio, drag its boundary in the
timeline to retime it. The system rejects a retime that would overlap the previous or
next word, so you can't accidentally create overlapping captions.

## Protecting a range

Mark a range of the timeline as protected to stop any automated pass (auto-cut,
reframe, zoom) from touching it — useful for a moment you've hand-tuned and don't want
an automated pass to undo.
