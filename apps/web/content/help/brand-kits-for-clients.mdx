## Setting up a brand kit

A brand kit bundles a caption style with a logo, watermark and font set. Create one
per client from Settings → Brand kits, then apply it to that client's projects so
every export matches automatically.

## Client tags

Tag each project with the client it belongs to. Tags drive both the project list
filter and, on team plans, per-client usage reporting — so a shared workspace never
mixes up whose spend is whose.

## Switching clients mid-project

You can re-apply a different brand kit to an existing project at any time; captions
and canvas re-render against the new kit without losing any transcript edits.
