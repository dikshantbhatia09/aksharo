# Every format from one link (2026-09-29)

What each clip is prepared as, and why. Sizes and limits were checked on
2026-09-29 against the platforms' own help pages (Instagram Help Centre, Meta
Business Help Centre for Facebook, YouTube Help, X Help Centre, Pinterest
Help, WhatsApp Help, Threads) and current 2026 size guides. They are what this
product makes, not every size a platform accepts. The code copy is
`packages/repurpose-contracts/src/formats.ts`.

## The files

Platform formats share picture shapes, so the work is done once per file.

**Videos (four per clip, captions burned in, plus a clean copy of each):**

| Shape | Size | Used for |
|---|---|---|
| 9:16 | 1080 x 1920 | Instagram Reel and Story, Facebook Reel and Story, YouTube Short, WhatsApp status, Threads video, Pinterest video pin, TikTok |
| 4:5 | 1080 x 1350 | Instagram and Facebook feed video |
| 1:1 | 1080 x 1080 | Instagram square post, X square video |
| 16:9 | 1920 x 1080 | YouTube video, Facebook landscape video, X video |

**Images (taken from those videos):**

| File | From | Size | Used for |
|---|---|---|---|
| portrait-post | 4:5, captioned | 1080 x 1350 | Instagram and Facebook image post, Threads image |
| carousel (5 slides) | 4:5, captioned | 1080 x 1350 | Instagram carousel (up to 20 slides allowed) |
| square-post | 1:1, captioned | 1080 x 1080 | YouTube community post |
| landscape-post | 16:9, captioned | 1600 x 900 | X image |
| vertical-image | 9:16, captioned | 1080 x 1920 | WhatsApp status image |
| pin | 9:16, captioned | 1000 x 1500 | Pinterest pin (2:3) |
| thumbnail | 16:9, captioned | 1280 x 720 | YouTube thumbnail |
| youtube-banner | 16:9, clean | 2560 x 1440 | YouTube channel banner (safe area 1546 x 423) |
| facebook-cover | 16:9, clean | 1702 x 630 | Facebook page cover (shown 851 x 315; phones keep the middle 640 x 312) |
| facebook-event-cover | 16:9, clean | 1920 x 1005 | Facebook event cover |
| facebook-group-cover | 16:9, clean | 1640 x 856 | Facebook group cover |

Covers and banners use a clean frame: captions across a channel header read as
a mistake. Each crop is centred across the picture and placed down it at the
speaker's face.

## Length limits the run page warns about

Instagram Reel 3 min, Instagram Story 60 s, Facebook Reel 90 s, Facebook
Story 60 s, YouTube Short 3 min, WhatsApp status 90 s, Threads video 5 min,
X 2 min 20 s (standard accounts), Pinterest video 15 min. A clip may run up to 3 min,
so the page warns per place; a clip is never cut shorter to fit.

## Other notes from the research

- Instagram's profile grid now previews posts at 3:4, so faces and words
  should stay away from the top and bottom of a 4:5 post.
- Instagram landscape posts are 1080 x 566 (1.91:1); this product makes the
  16:9 X image instead and does not make a separate 1.91:1 file.
- Facebook and Instagram Stories keep the top and bottom ~250 px under
  interface; the caption placement keeps captions off faces, not off those
  bands.
